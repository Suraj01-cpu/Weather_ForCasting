🚀 About The Project

Weather Forecasting Web App is a frontend-based weather application developed using HTML, CSS, and JavaScript.

The application allows users to:

📍 Get weather information based on their current location
🔍 Search weather information by city name
🌡️ View current temperature
🌤️ View weather conditions and weather icons
💨 Check wind speed
💧 Check humidity
☁️ Check cloudiness
🏳️ View the country's flag
⚡ See a loading state while fetching weather data

The project uses the OpenWeatherMap API to retrieve real-time weather information.

✨ Features
📍 Current Location Weather

Users can click "Grant Access" to allow the browser to access their location.

The application then:

📍 User Location
      ↓
🌐 Geolocation API
      ↓
📌 Latitude & Longitude
      ↓
☁️ OpenWeatherMap API
      ↓
🌦️ Weather Information
🔍 Search Weather

Users can switch to the Search Weather tab and enter a city name.

🔍 Enter City
      ↓
📡 API Request
      ↓
🌐 OpenWeatherMap
      ↓
📊 Weather Data
      ↓
🖥️ Display Results
🌡️ Weather Information

For each location, the application displays:

Information	Description
🏙️ City	Name of the location
🏳️ Country	Country flag
🌤️ Weather	Current weather condition
🌡️ Temperature	Current temperature in °C
💨 Wind Speed	Current wind speed
💧 Humidity	Humidity percentage
☁️ Cloudiness	Cloud coverage percentage
